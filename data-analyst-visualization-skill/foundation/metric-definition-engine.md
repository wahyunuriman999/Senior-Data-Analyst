# Metric Definition Engine
Every metric must be explicitly defined before analysis.
Do not assume standard definitions.
For every KPI, establish:
- **Numerator**: Exact formula and filters.
- **Denominator**: Exact formula, base population, and filters.
- **Grain**: e.g., User x Month.
- **Time Window**: e.g., Trailing 30 Days.
- **Exclusions**: e.g., Exclude internal test accounts.
- **Caveats**: Known data lags or measurement issues.
