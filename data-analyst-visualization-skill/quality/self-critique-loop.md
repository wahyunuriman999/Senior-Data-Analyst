# Real Self-Critique Loop
Execute this explicit protocol for all outputs:
1. **CRITIQUE**: What is wrong? (e.g., "The line chart has 15 lines, creating a spaghetti effect.")
2. **WHY**: Why is it wrong? (e.g., "Violates readability and visual grammar precision limits.")
3. **SEVERITY**: Major.
4. **FIX**: "Switch to a small multiples layout (faceted line charts)."
5. **RENDER & COMPARE**: Ensure the fix actually improves comprehension.
6. **PASS**: Ship only if passed.
