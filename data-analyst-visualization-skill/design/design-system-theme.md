# Design & Theme Engine
Rules extracted from reference analysis:
- **Corporate High-Density**: Grid constraints, low whitespace, semantic red/green/black.
- **SaaS Clean**: Card-based, generous whitespace, teal/blue accents, soft shadows.
- **Cinematic Dark**: Dark backgrounds, glowing accents (gold/cyan), high contrast, avoid 3D.
Typography: Strong hierarchy. Axis labels must be muted (e.g., gray) compared to data labels.
