# Dashboard Generators

Python scripts that produced the reference dashboards in
`data-analyst-visualization-skill/proof/examples/` and the `assets/*.jpg`
screenshots. They are **templates**, not a general engine: each script
hardcodes one dashboard's layout, data, and copy.

| Script | Purpose (by name/convention) |
|---|---|
| `build_apex.py` | Main Apex dashboard builder |
| `deepen_apex.py` | Deepens/enriches a generated dashboard |
| `phase_i_builder.py` | Phase I dashboard builder |
| `phase_1_1_fixer.py` | Fix-ups for Phase I.1 outputs |
| `generate_dashboard_v2.py` / `generate_dashboard_v3.py` | v2/v3 dashboard iterations |
| `generate_cross_filter_dashboard.py` | Cross-filter proof dashboard |
| `generate_retention.py` | Retention/cohort dashboard |
| `forensic_correction_retention.py` | Corrected retention rebuild |
| `inject_echarts.py` | Inlines ECharts into HTML (zero-CDN mandate) |
| `patch.py` | Ad-hoc patches |
| `update_skill.py` | Syncs generated content back into the skill docs |

> Note: these scripts predate the v2 standard (`design/tokens.json`,
> Fakta Terverifikasi, universal click-to-filter). Outputs generated by them
> may not pass `validator/apex_validate.py` — regenerate or adapt as needed.
